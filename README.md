📊 Network Traffic & Threat Analytics Dashboard

An end-to-end data analytics project that analyzes enterprise network traffic using SQL, Python, and Power BI.

---

📖 Project Overview

This project demonstrates a complete analytics workflow from raw data to an interactive dashboard.

The project includes:

- Excel data inspection
- SQL data analysis
- Python data cleaning
- Interactive Power BI dashboard

---

🎯 Objectives

- Analyze network traffic
- Monitor bandwidth utilization
- Detect packet loss
- Identify security threats
- Evaluate downtime across departments

---

 🛠 Tools & Technologies

📁 Dataset

The dataset contains simulated enterprise network traffic including:

- Timestamp
- VLAN ID
- Department
- Protocol
- Source IP
- Destination IP
- Bandwidth Usage
- Packet Loss
- Downtime
- Threat Flag

---

🗄 SQL Analysis

SQL was used to answer business questions such as:

- Peak network traffic hours
- Average bandwidth by department
- Packet loss by VLAN
- Downtime by department
- Threat distribution by protocol

---

🐍 Python Data Cleaning

Python (Pandas) was used to:

- Remove duplicates
- Handle missing values
- Convert timestamps
- Standardize text
- Export a clean dataset for Power BI

---

📊 Power BI Dashboard

The dashboard contains:

- KPI Cards
- Traffic Trend
- Threat Analysis
- VLAN Performance
- Department Traffic
- Downtime Analysis
