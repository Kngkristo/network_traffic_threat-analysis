📊 Network Traffic & Threat Analytics Dashboard

An end-to-end data analytics project that analyzes enterprise network traffic
to identify bandwidth trends, packet loss, downtime, VLAN performance, 
and potential security threats using Excel,SQL,Python, and Power BI.


📖 Project Overview

This project demonstrates a complete data analytics workflow using a simulated enterprise network traffic dataset.

The workflow includes:

Data inspection in Excel
SQL analysis using MySQL
Data cleaning and transformation using Python (Pandas)
Interactive dashboard creation in Power BI

The objective is to help network administrators monitor traffic, identify threats, analyze bandwidth utilization,
and detect downtime patterns.
